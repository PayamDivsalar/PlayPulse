مجموعه مستندات فنی پروژه

این مجموعه، معماری نرم‌افزار، طراحی پایگاه‌داده، جمع‌آوری داده، تحلیل ترافیک شبکه، تحلیل احساس، استقرار production با Ansible، اعتبارسنجی زیرساخت و اسکریپت‌های عملیاتی پروژه را در قالب یک مرجع یکپارچه مستند می‌کند.

▣
ARCHITECTURE & API

Application Registry

معماری لایه‌ای، جریان درخواست‌ها، طراحی API، تصمیمات مهندسی و استراتژی تست زیرسیستم مدیریت اپلیکیشن‌ها.

DATA COLLECTION

Play Store Crawler

مدل همزمانی، Rate Limiting، Dependency Injection، فلوی کامل خزش، قرارداد داده و استراتژی تست زیرسیستم کراولر.

NETWORK · PCAP

Network Analyzer

هستهٔ خالص تحلیل PCAP، شاخص‌های کیفیت و حجم شبکه، متدولوژی ضبط PCAPdroid، انتشار به Kafka و استراتژی تست Unit/Oracle/Live.

DATA PERSISTENCE

Storage Consumer

مصرف تاپیک‌های Kafka، تضمین‌های Idempotency، ترتیب Write-before-Commit، صف پیام‌های مرده، مالکیت اسکیما و مدل همزمانی زیرسیستم ذخیره‌سازی.

NLP · ANALYSIS

Sentiment Analysis

Job دسته‌ای طبقه‌بندی احساس نقدها با Cardiff XLM-R، مالکیت ستون reviews.sentiment، اجرا در venv/Docker و استراتژی تست Unit/Integration/Smoke.

Ansible Production Deploy
